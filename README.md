# NOIR — каталог фильмов

Многостраничный статический сайт-каталог фильмов на HTML/CSS/JavaScript.

## Страницы
- Главная — `index.html`
- Каталог с поиском и фильтрами — `catalog.html`
- Умный выбор фильма — `pick.html`
- Тематические подборки — `collections.html`
- Карточка фильма — `movie.html?id=...`

## Важно
Сайт не хранит и не раздаёт пиратские копии фильмов. Карточки ведут к информационным страницам и легальным источникам/поиску просмотра.
