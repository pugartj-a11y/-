# MiniPlay

Многостраничный сайт с мини-играми в цветах серый / красный / голубой.

## Страницы
- Главная — index.html
- Игры — games.html
- О сайте — about.html
- Клик-мастер — clicker.html
- Найди пару — memory.html
- Реакция — reaction.html

Проект использует чистые HTML, CSS и JavaScript и готов для GitHub Pages.
